Get started

Up in two commands.

Docker or native install — your choice. No configuration maze.

# Clone the repo
❯ git clone https://github.com/Abi5678/Matclaw.git && cd Matclaw
 
# Copy environment template and add your API key
❯ cp .env.example .env
❯ echo "NVIDIA_API_KEY=your_key_here" >> .env
 
# Launch with Docker Compose
❯ docker compose up
 
✓ MatClaw running at http://localhost:8000
# Clone and run the installer
❯ git clone https://github.com/Abi5678/Matclaw.git && cd Matclaw
❯ chmod +x install.sh && ./install.sh
 
# Add your API key
❯ echo "NVIDIA_API_KEY=your_key_here" >> .env
 
# Start MatClaw (opens browser automatically)
❯ matclaw
 
✓ MatClaw running at http://localhost:8000
Capabilities

Built for engineers
who ship.

Core

Multi-Agent DAG Swarm

Define complex pipelines as directed acyclic graphs. Specialized agents — Researcher, Planner, MATLAB Executor — coordinate in parallel, with topological ordering ensuring the right execution sequence every time.

Safety

Human-in-the-Loop Gates

Every destructive action pauses for confirmation. Audit checkpoints and MCP tool approval make MatClaw safe for production engineering workflows.

Live MATLAB Execution

Three-path dispatcher: run provided code directly, generate-then-execute with LLM, or LLM text-only. Real MATLAB Engine for Python — no sandboxes, no simulations.

Fast Inference

Powered by NVIDIA Nemotron Ultra 253B via NVIDIA API. Swap to any OpenAI-compatible endpoint in Settings — Anthropic, OpenAI, Google, or your own hosted model.

Prompt Optimizer

Type a vague agent idea. Click Optimize. Get a detailed, production-ready system prompt — engineered by the LLM itself.

Monaco Code Editor

Multi-tab VS Code editor in-browser. Write MATLAB, save to disk, run directly in the agent swarm — all without leaving MatClaw.

Persistent Sessions

SQLite-backed session history syncs across restarts. Write-through localStorage keeps the UI instant while the server catches up in the background.

The loop

Research. Plan.
Execute. Verify.

1

Research

The Task Router analyzes your request and decomposes it into a directed acyclic graph of specialized sub-tasks.

2

Plan

Agents select tools, assign responsibilities, and order execution steps based on dependencies — automatically.

3

Execute

MATLAB code runs natively. Results stream back in real-time via SSE. Errors trigger automatic retry loops with self-correction.

4

Report

Plots, logs, and structured outputs land in the flow dashboard. Every artifact is saved, versioned, and reviewable.

Built to verify.

MatClaw doesn't just generate code — it runs it, checks output, and corrects itself until the result is right.

Human-in-the-loop approval before any destructive action

Immutable audit trail of every agent decision and tool call

MCP-compatible tool registry — bring your own tools

Session isolation — each task runs in its own context
